Explore repeated context

Repeat a pair with the same system prompt. Prefix reuse can affect timings, but cache state, current traffic, scoring policies, and overhead also contribute. Neither path is guaranteed to win.

Read the timing correctly

TTFT appears only when the server observes streamed content. Missing measurements stay unavailable. Total time, token counts, failures, and execution order provide context for each sample.

Understand the limits

The baseline and llm-d paths have different routing and authentication overhead. Sequential runs reduce direct contention but encounter different cache states. This is not an isolated scheduler benchmark or a cross-node KV-transfer demonstration.
