# Reset the test drive

Reset the experiment rather than the entire cluster. Never delete shared namespaces, the DSC, or existing pools to restart a presentation.

| Participant action | Reset procedure |
|---|---|
| Edited a notebook | Restore that notebook or open a clean copy from Git |
| Created a Ray/MLflow run | Preserve evidence; stop only the identified job and submit a new run |
| Exhausted a short MaaS quota | Wait for its window and test recovery with the same subscription |
| Changed a prompt or configuration | Revert the commit or restore a known version, then observe Argo |
| Started an experimental GPU model | Save results, stop only that owned workload, and check cloud/GPU inventory |
| Key expired | Issue a new time-limited key and update the Secret without broadening access |

Argo uses prune=false. Removing a manifest does not delete the live object. Deleting persistent data requires an explicit owner decision and appropriate backup.

Before reducing GPU capacity, verify that no unrelated workload depends on the pool, stop or move Aurora workloads, and check the final capacity bound. Preserve the original inference pool. Do not combine L40S and MIG profiles without counting every physical GPU and transition allowance.

Canonical business data lives in `data/`. The MCP ConfigMap snapshots are generated by `sync_data.py`. Publish a new forecast through the [Ray workflow](../labs/ray.md), preserving its model version and source run ID. Never edit measured results to make them look better.
