# Private Qwen inference and llm-d routing rehearsal

This opt-in overlay deploys Qwen3-4B-Instruct-2507 behind a dedicated ClusterIP Gateway. It removes the base model's MaaS discovery/access/subscription resources: a private benchmark address must not be advertised as a customer-reachable MaaS model.

The Gateway has one listener and one HTTPRoute, accepts routes only from its own namespace, and has an ingress NetworkPolicy admitting only same-namespace pods matching both `app=ogx` and `app.kubernetes.io/instance=lsd-genai-playground` on TCP8080. Monitoring collectors matching the exact RHOAI namespace and workload labels can scrape TCP15020; this does not grant inference access. Other pods remain denied. There is no public OpenShift Route or external load balancer. An authorized operator uses `oc port-forward` to the Gateway Service; native Playground uses its explicitly allowed OGX provider and forwards the user’s Kubernetes token. The same-namespace OGX→Gateway hop is HTTP on a private ClusterIP, not end-to-end TLS. Browser ingress and the API port-forward use TLS separately; do not describe this internal hop as encrypted. No shared administrator token is embedded in the provider. KServe generates `showroom-inference-authn`, which validates a Kubernetes token and performs model access reviews. Do not disable this policy to simplify a demo.

The raw vLLM backend is separately isolated by `showroom-qwen-backend-private`: TCP8000 accepts only this model’s Gateway, its exact endpoint-picker scheduler, and the selected RHOAI collectors. Native Playground must use the Gateway and cannot call the raw backend directly. This closes an independently reproduced unauthenticated direct-backend path. Authorized operators with Kubernetes exec/port-forward permissions remain privileged. Protect namespace workload/RBAC administration because users able to create or relabel trusted pods can affect NetworkPolicy identities.

The model has two replicas, one per distinct host, with hard pod anti-affinity. The reference overlay selects `g6e.2xlarge` on the dedicated showroom pool. The initial reference rollout adds placement constraints while retaining one Ready replica, then scales to two after the replacement is Ready; this avoids a rolling-update deadlock while both GPU hosts are occupied. Do not claim two-node readiness until two actual backend pods and successful requests prove it.

Why isolate the Gateway: the installed shared gateway produced incorrect endpoint-picker overrides when multiple model routes shared a listener. Giving Qwen's rules unique names did not resolve it. Moving its route to this dedicated listener restored the shared Llama route's own picker target. Qwen's authenticated responses and `llm_d_epp_request_total` increases prove actual private request processing. The shared MaaS `/v1/chat/completions` path bypassed EPP without a model header. A later test proved that the matching `X-Gateway-Model-Name` header returned a full successful Llama response and increased its EPP counter; repeated GuideLLM qualification later produced empty streaming payloads. The sustained runner therefore uses the working no-header MaaS path, and Qwen provides the separate private EPP demonstration.

The installed environment exhibited a related shared-listener routing limitation. See [Red Hat's 3.5 known issues, INFERENG-6962](https://docs.redhat.com/en/documentation/red_hat_openshift_ai_self-managed/3.5/html/release_notes/known-issues_relnotes) and the [official llm-d deployment guide](https://docs.redhat.com/en/documentation/red_hat_openshift_ai_self-managed/3.5/html/deploy_models_using_distributed_inference_with_llm-d/index). Configuration and observed symptoms are recorded separately; the known issue is not proof of a complete root-cause diagnosis.

The pinned Qwen runtime enables Hermes tool parsing and automatic tool choice. A real native-auth request returned `get_stock({"sku":"AS-001"})`; this is protocol acceptance, not general agent safety approval. The registry candidate remains unapproved pending its separate evaluation gates.
